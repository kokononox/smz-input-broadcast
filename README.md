# smz-input-broadcast

Standalone development of authorized one-way input mirroring from a master Classroom Studio Pico to client HID devices. The two-sensor master runtime is built by applying a local overlay to a pinned `smz` source checkout; the `smz` repository is never changed by this project.

See [the Persian dual-sensor wiring/build note](docs/ONE_WAY_MIRROR_DUAL_SENSOR.fa.md).
