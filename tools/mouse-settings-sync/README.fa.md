# ابزار یک‌بارمصرف همسان‌سازی تنظیمات ماوس ویندوز

این ابزار تنظیمات **سرعت نشانگر ویندوز** و **شتاب/آستانه‌های ماوس** را از یک سیستم صادر می‌کند و پس از تأیید، روی سیستم دیگر اعمال می‌کند. تنظیمات فقط برای کاربر ویندوزی که برنامه را اجرا کرده تغییر می‌کند؛ نصب سرویس، دسترسی مدیر، hook ورودی، یا ارتباط شبکه‌ای لازم نیست.

## روش استفاده

1. همین برنامه را روی سیستم مادر اجرا کن و «ذخیره برای انتقال از مادر» را بزن.
2. فایل `smz-mouse-settings.json` را با USB یا روش امن دیگری به سیستم کلاینت منتقل کن.
3. برنامه را روی کلاینت اجرا کن، «اعمال فایل روی این سیستم» را بزن و همان فایل را انتخاب کن.
4. قبل از تغییر، برنامه از تنظیمات فعلی کلاینت روی Desktop پشتیبان می‌گیرد و برای اعمال، تأیید می‌خواهد.
5. اگر نتیجه خوب نبود، فایل `SMZ-mouse-backup-*.json` را با همین ابزار روی کلاینت اعمال کن. پس از پایان می‌توان فایل اجرایی را حذف کرد؛ تنظیمات اعمال‌شده باقی می‌مانند.

این ابزار DPI سخت‌افزاری موس یا نرخ گزارش‌دهی آن را تغییر نمی‌دهد و تضمین نمی‌کند نشانگرها همیشه دقیقاً هم‌مکان باشند. فقط تنظیمات سرعت و شتاب خود ویندوز را همسان می‌کند.

## ساخت

```powershell
dotnet publish .\SmzMouseSettingsSync.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\publish
```
