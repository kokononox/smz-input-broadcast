# ابزار Windows برای پایش لینک Pico

این ابزار کوچک فقط برای آزمون فریمور `firmware/link_test` است. روی کامپیوتر مادر پورت USB CDC مربوط به Pico مادر را باز می‌کند و گزارش‌های سریال را نشان می‌دهد؛ خودش ورودی موس یا صفحه‌کلید را نمی‌خواند یا ارسال نمی‌کند.

## پیش‌نیاز و ساخت در Windows 11

1. .NET 8 SDK را نصب کنید.
2. در PowerShell به این پوشه بروید.
3. اجرا کنید:

```powershell
dotnet publish .\SmzLinkMonitor.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

فایل اجرایی در مسیر `bin\Release\net8.0-windows\win-x64\publish\SmzLinkMonitor.exe` ساخته می‌شود. اگر هنگام ساخت، بستهٔ `System.IO.Ports` در دسترس نباشد، اتصال اینترنت برای دریافت بسته لازم است.

## استفاده

1. فریمور نقش MASTER را روی Pico مادر و فریمور نقش CLIENT را روی یک Pico کلاینت فلش کنید.
2. سیم‌کشی UART را با بردهای خاموش انجام دهید: GP8 مادر به GP9 کلاینت، GP9 مادر به GP8 کلاینت، و GND به GND.
3. Pico مادر را با USB به همین کامپیوتر وصل کنید؛ COM آن در برنامه انتخاب می‌شود.
4. اگر Serial Monitor دیگری پورت را باز کرده، آن را ببندید؛ سپس در برنامه COM مادر را انتخاب و «اتصال» را بزنید.
5. وضعیت USB فقط باز بودن COM مادر را نشان می‌دهد. دریافت ACK از فریمور کلاینت، سلامت لینک PicoبهPico را تأیید می‌کند. RTT نمایش‌داده‌شده زمان رفت‌وبرگشت است، نه تأخیر یک‌طرفه.

برنامه سرعت USB CDC را روی 115200 baud می‌گذارد؛ لینک UART بین Picoها طبق فریمور آزمون روی 1,000,000 baud است. CRC در این آزمون فقط برای تشخیص خطای تصادفی است و رمزنگاری نیست؛ آزمون هیچ دادهٔ موس یا صفحه‌کلید حمل نمی‌کند.

اگر COM باز است ولی ACK نمی‌رسد، این برنامه فقط وضعیت را گزارش می‌کند؛ ابتدا نقش فریمورها، اتصالات GP8/GP9 و GND و گزارش‌های هر دو برد را بررسی کنید.
