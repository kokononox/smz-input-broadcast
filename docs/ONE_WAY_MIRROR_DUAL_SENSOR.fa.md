# آینهٔ یک‌طرفه برای فریمور دوحسگرهٔ Classroom Studio

این شاخه، آینهٔ ورودی را به **runtime بومی Pico با منبع دوحسگره** اضافه می‌کند؛ مخزن `smz` فقط به‌صورت checkout موقت و در commit ثابت `dc81e1d8f6202ac28cc3f086f921b5c3e339ef88` خوانده می‌شود و هیچ فایلی در آن تغییر یا commit نمی‌شود.

## سیم‌بندی یک‌طرفه

- برد مادر: `UART1 TX / GP8` به ورودی `UART1 RX / GP9` همهٔ کلاینت‌ها.
- `GND` برد مادر و همهٔ کلاینت‌ها مشترک باشد.
- `GP9` برد مادر و `GP8/TX` کلاینت‌ها وصل نشوند؛ مسیر پاسخ/ACK وجود ندارد.
- سیگنال UART سطح ۳٫۳ ولت است. سیم‌کشی کوتاه و زمین مشترک لازم است؛ پیش از اتصال چند برد، با یک کلاینت و سپس با هشت کلاینت آزمایش شود.
- کلاینت HID فقط وقتی ورودی را به کامپیوتر می‌فرستد که کلید ARM خودش فعال باشد؛ قطع‌شدن فریم‌ها باعث آزادسازی کلیدها و دکمه‌های نگه‌داشته‌شده می‌شود.

فریم‌ها شامل شمارهٔ توالی، زمان، CRC16، حرکت نسبی ماوس، کلیک/دکمه/اسکرول و snapshot دوره‌ای وضعیت کلیدها و دکمه‌ها هستند. مدت کلیک آینه‌ای از وسط بازهٔ hold تنظیم‌شده انتخاب می‌شود؛ بنابراین ممکن است با مدت تصادفی اجرای آردوینو دقیقاً یکسان نباشد، ولی snapshot وضعیت را دوباره همگام می‌کند. Snapshot هر ۱۰۰ میلی‌ثانیه، وضعیت جاافتاده را همگام می‌کند؛ watchdog کلاینت با نبود فریم، HID را آزاد می‌کند.

## ساخت

Workflow فایل‌های test master/client را همراه با runtime دوحسگره می‌سازد. فایل
`classroom-studio-dual-sensor-mirror-smoke.uf2` یک **smoke build** است: runtime دوحسگره و mirror دارد، اما برنامهٔ داخلی آن `abvm_dual_guard_smoke.amsj` تستی است، نه برنامهٔ اختصاصی پروژهٔ کاربر. برای UF2 نهاییِ برنامهٔ کاربر، فایل `.abp` تأییدشدهٔ همان پروژه باید در runtime قرار بگیرد؛ ساخت این smoke UF2 به‌تنهایی جایگزین آن برنامه نیست.

پشتیبانی نرم‌افزاری از ارسال fan-out پیاده شده است؛ تعداد هشت کلاینت و کیفیت سیگنال باید روی سخت‌افزار واقعی تأیید شود.
